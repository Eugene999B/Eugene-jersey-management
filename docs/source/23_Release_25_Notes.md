# Release 25 Notes

Scope captured from the platform owner:

1. Platform-commercial changes must apply immediately for the sole administrator; no second administrator approval workflow.
2. POS credit sales must clearly support selecting an existing customer or creating a new customer, and every new credit sale must add to that customer's outstanding debt history.
3. Shop registration status must be clearly separated from marketplace/storefront visibility, with an obvious owner control to turn the online shop on or off.
4. Shop owners and staff must be able to see their Login ID in the authenticated workspace.
5. Design Studio must provide a downloadable quick operating guide.
6. Every platform-admin page must expose page help plus a downloadable complete administrator handbook covering shops, suppliers and all platform features.
