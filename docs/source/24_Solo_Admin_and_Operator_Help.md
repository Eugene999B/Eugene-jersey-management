# Solo Administrator and Operator Help Decision

Updated: 2026-07-28

The current EJM platform owner is the sole platform administrator and business decision-maker. Commercial configuration changes must therefore apply immediately after the authenticated administrator saves them. The system must keep an immutable audit/version history, but it must not require another administrator to approve the same owner's work.

This release also makes credit-sale customer handling, storefront visibility, Login IDs and downloadable operator guidance explicit in the user interface.
